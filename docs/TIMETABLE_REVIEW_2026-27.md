## How split and combined lectures are stored

- **Split period** — one class, several groups at once (e.g. Sanskrit / IT / Beauty electives, or Hindi-medium and English-medium groups). One Master_Schedule row; the Subject, Teacher and Room cells list the groups in the same order, separated by ` / `. Co-teachers of one group are joined with ` + `. A group with no teacher is `-`.
- **Medium** — `(H.M)` / `(E.M)` after a subject marks the Hindi- or English-medium group, as in the Excel (e.g. `Physics (H.M) / Chemistry (E.M)`). 11th C and 12th C are one class each; their medium groups are split periods.
- **Combined lecture** — one teacher teaches the same subject to several sections at once (e.g. 12th B + 12th D Physics). Each section keeps its own row with the same subject; the clash check treats same teacher + same subject + same period + same grade as one lecture. A medium mark on only one of the sections (`Hindi` in 11th B, `Hindi (E.M)` in 11th C) is still the same lecture; `(H.M)` and `(E.M)` groups at once are a clash.
- Same teacher + same period + **different** subjects is a real clash.
